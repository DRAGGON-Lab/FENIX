# BioIR Design and Experiment schemas — pending ADR-P01

Future normative versioned documents will define separate immutable Design and Experiment revisions, typed component/port semantics, stable IDs, exact revision/digest references, dimensional quantities, interventions and observables.

**No schema has been ratified.** Do not implement or assume fields yet.

Review candidate: [ADR-P01 — M0-compatible BioIR subset](proposals/ADR-P01.md), with a
candidate JSON Schema and illustrative documents. These remain **PROPOSED**;
they are not normative schemas or approved conformance fixtures.
This subset is an initial milestone; BioIR's architectural scope includes nested
biological systems beyond current execution support. The proposal requires a
versioned extension and migration strategy without rewriting existing identities.
