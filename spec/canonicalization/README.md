# Canonicalization — ADR-P03 proposed

The [ADR-P03 proposal](proposals/ADR-P03.md) defines M0 FIR pre-normalization,
RFC 8785/JCS exact bytes and a versioned SHA-256 identity preimage. The
[candidate catalog and independent serialization checks](../../conformance/canonicalization/README.md)
are REVIEW REQUIRED, not approved golden references. P01/P02 remain ratified;
P03 needs explicit human PI signoff. No native FIR normalizer, parser or compiler
is implemented here. P01 BioIR hashing is unchanged.
