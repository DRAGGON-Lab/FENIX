# Canonicalization — ADR-P03 ratified

The [ADR-P03 contract](proposals/ADR-P03.md) defines M0 FIR pre-normalization,
RFC 8785/JCS exact bytes and a versioned SHA-256 identity preimage. The
[candidate catalog and independent serialization checks](../../conformance/canonicalization/README.md)
are REVIEW REQUIRED, not approved golden references. The human PI ratified P03
on 2026-11-14 at reviewed revision `fdee54e5ebc5226c0a83810872311cc8cbbec3fd`.
The drafting-era path remains stable; the ADR's ratification record determines
its status. Independent fixture and implementation approval remain pending.
No native FIR normalizer, parser or compiler is implemented here. P01 BioIR
hashing is unchanged.
