# ADR-001 — Dual-native FENIX monorepo scaffold

**Status:** Accepted as *non-normative scaffold structure*, 2026-11-14. Exact BioIR/FIR/JCS contracts remain pending.

## Context

Architecture v0.1 commits to two independent native packages, one shared language-neutral contract, scientific gatekeeping and agent-ready incremental work.

## Decision

Create a monorepo with independently installable Python and Julia package skeletons, independent smoke tests and CI, placeholders for specs/conformance/examples, and binding AGENTS.md instructions. Keep scientific schemas, mathematical implementation and reference digests out until approved ADR-P01–P03. Distribution/module names remain provisional until package governance ADR-P06.

## Alternatives and tradeoffs

- **One monorepo/two packages (chosen):** simple shared fixtures and CI, requires strict package isolation.
- **Two repositories:** fewer shared files, higher coordination and compatibility overhead.
- **One language wrapping another:** easier single installation, violates independent native execution.

## Consequences

Smoke builds validate packaging only. CI and future version matrices add maintenance. No GUI, database, server, Docker Compose, standard adapter, Catalyst or scientific model has been authorized in this scaffold.

## Risk mitigation and revisit

Independent package tests now; contract-first scientific tests after ADR ratification. Revisit on naming collision, release constraints or evidence monorepo cannot support isolated native packages. Biological changes require separate PI-approved ADRs and independent fixtures.
